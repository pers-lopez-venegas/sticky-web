Primer inicio

Abre el instalador de Sticky en Windows x64. Si lo recibiste en un archivo ZIP, extráelo primero.

  • Elige Estudio de stickers para trabajar con imágenes, quitar fondos y preparar bordes.
  • Elige Editor de planillas para organizar una hoja e imprimir o exportar. En Nuevo documento también puedes elegir Vinil por capas.

La evaluación dura 90 días desde el primer inicio. Si ya tienes una clave, abre Comprar / activar…, pégala en Clave de licencia y pulsa Activar.

Estudio de stickers

  1. Pulsa Cargar imagen. El Estudio también tiene extractores de imágenes de PDF, Word y CDR, de sprites y de fotogramas GIF.
  2. Ajusta las opciones de borde y pulsa Procesar. Para separar la figura de su fondo, elige un modelo y usa IA local + bordes. Si quieres retocar la selección, marca Abrir editor después de usar IA.
  3. Revisa la salida y usa Guardar Actual para guardar un resultado. Si vas a armar la hoja en Sticky, pulsa Enviar resultados al editor de planillas.

Ampliar una imagen con IA

Abre Mejorar imagen con IA, elige un modelo y un factor en Ampliar. Compara el original con el resultado antes de guardarlo.

Editar una imagen de la planilla

Selecciona las imágenes y pulsa Estudio en el editor. Al terminar, usa Reemplazar en planilla. El reemplazo conserva el tamaño y la posición. Si las imágenes tenían bordes de corte, vuelve a generarlos para la nueva silueta.

Editor de planillas

  1. En Archivo → Nuevo documento, elige Planilla, el tamaño de la página y su orientación. Si vas a cortar con tapete, selecciona el perfil correspondiente.
  2. Usa Archivo → Agregar imágenes o vectores… (Ctrl+O). Para trabajar con páginas de un PDF, usa Archivo → Importar páginas de PDF….
  3. Arrastra las piezas para acomodarlas y usa los tiradores para cambiar su tamaño. Para varias copias de una misma pieza, selecciónala y usa Objeto → Repetir / crear copias….
  4. Guarda la planilla como .stk con Ctrl+S para poder editarla después.

Agregar una imagen desde Pinterest

Abre Archivo → Buscar imágenes en Pinterest…. Haz clic derecho sobre una imagen y elige Agregar a la planilla o Enviar al Estudio de stickers para procesarla primero.

Si necesitas volver a un paso anterior, abre Paneles → Historia. Si editas desde un paso anterior, se descartan los pasos posteriores de esa sesión.

Impresión y corte

  1. Para crear un contorno a partir de la transparencia de una imagen, selecciónala y abre Objeto → Crear o actualizar borde de corte… (Ctrl+B). Ajusta el margen, pulsa Actualizar vista previa y revisa el trazo antes de pulsar Generar bordes.
  2. Consulta Archivo → Vista previa de impresión para comprobar la hoja. Imprime con Ctrl+P o usa Archivo → Exportar documento como PDF… para guardar el diseño imprimible.
  3. Para guardar los trazos, elige Exportar líneas de corte como SVG… o Exportar líneas de corte para ScanNCut (FCM)… en Archivo.

LightBurn Camera Print & Cut

Con los bordes ya generados en la página actual, elige Archivo → Exportar para LightBurn Camera Print & Cut…. Obtendrás un SVG de corte y un PDF imprimible con las mismas marcas. Imprime ese PDF al 100 % para conservar la escala de las marcas.

Vinil por capas

  1. Abre Archivo → Nuevo documento, elige Vinil por capas y selecciona la máquina y el tapete.
  2. Importa piezas vectoriales de colores planos con Agregar SVG o dibuja con Pluma, Rectángulo, Círculo o Texto. Puedes cambiar las curvas con Nodos.
  3. Usa Capas de color para seleccionar todas las piezas del mismo color. Preparar tapete acomoda las piezas visibles en bloques por color y conserva su tamaño.
  4. Guarda el original editable como .stk y exporta los vectores en SVG o en FCM para ScanNCut desde Archivo.

Si agregas una imagen con Referencia para dibujar encima, se guarda en el proyecto. Los archivos de corte llevan los vectores.

Biblioteca de stickers

La biblioteca guarda imágenes reutilizables y permite ordenarlas por categorías, etiquetas y descripción.

  • Para incorporar archivos del equipo, abre Opciones → Importar imágenes… en el panel Biblioteca de stickers.
  • Para guardar piezas desde la planilla, selecciónalas y usa Objeto → Guardar selección en la biblioteca…. Puedes arrastrar imágenes de la biblioteca a otra planilla.
  • Para llevar tus imágenes a otro equipo, usa Opciones → Exportar categoría o selección…. En el otro equipo, abre Opciones → Importar paquete de biblioteca… y elige el archivo .stickylib.

Cuando vinculas una imagen, Sticky necesita que el archivo original siga disponible. El paquete .stickylib incluye una copia de las imágenes exportadas.

Archivos y recuperación

  • Abrir un proyecto. Usa Archivo → Abrir documento… (Ctrl+Mayús+O) para volver a editar una planilla o un documento de vinil en formato .stk. También puedes abrir un archivo con doble clic desde la pestaña Recientes de Nuevo documento.
  • Guardar una variante. Usa Archivo → Guardar como… para crear otro archivo con un nombre diferente.
  • Recuperar cambios. Si Sticky ofrece copias al volver al editor después de un cierre inesperado, elige los documentos que quieras recuperar. También puedes abrir la lista con Archivo → Recuperar documentos….

El autoguardado crea copias de recuperación por separado. Guarda el documento recuperado con Guardar o Guardar como… para conservar los cambios en tu proyecto.
